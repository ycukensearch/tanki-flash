# Танки Флэш
Первая браузерная флэш игра в 2026 году (не точно)
# ВАЖНО!
Игра не имеет никакого отношения к Tanki Online
# Как играть
Рекомендуем использовать ПК с клавиатурой или телефон с Bluetooth клавиатурой. 
# Клавиши
Стрелка Вверх - Движение вперед; стрелка вниз - движение назад; стрелка влево - поворот налево; стрелка вправо - поворот направо; пробел - выстрел.
